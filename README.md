# IpToSerialBridge_Esp8266

RU
"Прозрачный" мост между TCP/UDP (через WiFi) и последовательным портом UART0
для esp8266 на Arduino. Предназначено для пересылки пакетов ModBus на высоких
скоростях. Поделка делалось, т.к. не нашлось готовых рабочих решений для
скоростей 460800-4000000 МБит/сек.

EN
Transparent bridge between TCP/UDP (via WiFi) and UART0 serial port for esp8266
on Arduino. Designed for sending ModBus packets at high speeds The craft
was done because... there were no ready-made working solutions for speeds
460800-4000000 Mbit/sec.
